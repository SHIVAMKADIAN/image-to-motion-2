SCRIPT → UNDERSTAND THE SCENE → CAST THE CHARACTERS → MAKE CHARACTER SHEETS → IDENTIFY LOCATIONS / OBJECTS → BREAK THE STORY INTO VISUAL MOMENTS → DECIDE WHAT EACH SHOT SHOULD SHOW → WRITE THE PROMPT → GENERATE → CHECK → FIX → EDIT

Use the character reference for casting and identity; explain the rest (location, action, camera, lighting, dialogue, movement) directly in the prompt. The generated visuals replace a traditional storyboard.
