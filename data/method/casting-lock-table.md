Before generating many scenes, lock each recurring character's:
- Face — the same person stays recognisable
- Hair — changes make the character feel different
- Skin tone — keeps the character consistent
- Body / proportions — prevents shape drift
- Costume foundation — a consistent base look
- Overall appearance — one clear reference for the show

For recurring characters the reference image is the identity anchor.
