Tell the model which axis of the reference matters:
- World continuity: same set construction, lighting logic, atmosphere, production quality
- Action energy: same event still in progress, same intensity and physical weight
- Camera character: same cinematic register, operator presence, overall quality
- Voice + performance: same vocal character, delivery register, energy

Prompt wins on action; reference wins on texture and world feel. Pair with an image reference when character identity matters.
