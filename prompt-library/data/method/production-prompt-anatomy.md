Each block of a production clip prompt prevents one failure:
GLOBAL LOOK → style drift
REFERENCE USE → sheets rendered as frames, labels, watermarks
DIALOGUE AND SOUND RULES → wrong speaker, double speech, unwanted music or captions
ATTACH IN THIS ORDER → identity swaps
OPENING AND PHYSICAL POSITIONS → state at second 0
FIXED LOCATION GEOGRAPHY → left/right flips and teleporting actors
CAMERA AND ACTION CONTINUITY → moving actors when the camera changes
LIVE BACKGROUND PERFORMANCE → frozen extras
TIMED SHOTS → pacing, one dominant action per shot, lens per shot
FINAL STATE → clip-to-clip handoff

Use the whole stack for long multi-character clips; for simple shots use the short templates instead.
