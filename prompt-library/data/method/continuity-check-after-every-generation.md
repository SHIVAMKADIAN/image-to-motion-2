---
Character — same face, hair, body, overall appearance
Costume — matches the script and nearby shots
Location — still feels like the same place
Lighting — makes sense for the scene and time
Props — important objects stay consistent
Position — the action makes sense from the previous shot
Story — the shot communicates the intended beat
Performance — the intended level of emotion
Physics — bodies and objects move naturally
