- Attach references in a stated order and label each: [Image N] = filename, then one line saying what to preserve (identity, costume, location geometry).
- Sheets establish identity and design only — never use a sheet or collage as the starting frame. Never render labels, panels or watermarks.
- Add voice continuity per character in the attach line (age, register, energy) so voices stay distinct.
- Keep principals distinct from each other and from extras; say how two similar characters differ.
- Location sheets are geometry masters: preserve doors, trees, steps and pillars across coverage.
- A video reference carries world, texture and camera feel, not exact identity; pair it with an image reference for faces.
