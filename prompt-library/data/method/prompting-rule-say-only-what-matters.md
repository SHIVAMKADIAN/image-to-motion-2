---
title: Prompting Rule: Say Only What Matters
category: method
medium: [image, video]
models: [any]
tags: [prompting, length, rule]
source: creator-handover-guide
---
If it is important to the shot, write it clearly. If it is not important, do not add it just to make the prompt longer.

Simple shot (one person sitting and speaking): a short prompt is enough.
Detailed shot (camera moves + dialogue + object interaction + timing + reaction): many variables must happen in order, so more explicit instructions reduce ambiguity.

Write as much as the shot needs, not as much as possible.
