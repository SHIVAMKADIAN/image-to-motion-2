Wrong face → strengthen the character reference / identity instruction
Wrong costume → make the costume requirement clearer
Wrong action → simplify the action and describe the sequence
Wrong camera → describe the starting position and exact movement
Object moves incorrectly → describe cause → direction → contact → final position
Too many people / objects → remove them and explicitly say no extra characters/objects
Too much acting → tell the character to stay calm, subtle or serious
Looks too artificial → improve natural materials, lighting, depth and physical behaviour
Shot doesn't tell the story → go back to the script and reconsider what needs to be shown

Change one thing at a time.
