1. Establish the world — wide establishing view (location, scale, weather, time)
2. World → people — character-focused view
3. Show the relationship — two-character interaction
4. Use movement to connect locations — vehicle / transition
5. Change the point of view — interior vehicle view
6. Let ordinary details build the location — rural location
7. Give the important face attention — close-up
8. Establish the room before the emotional close-up — room / situation
9. Let the face carry the tension — emotional close-up (or: objects tell the story, overhead)
10. Show an important object clearly — detail / evidence
11. Give a small physical action its own moment — action detail
12. Return to the character's perspective — interior character view

Each shot is chosen for what it communicates, not only because it looks good.
