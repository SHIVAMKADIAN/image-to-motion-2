---
title: Camera Matches Emotion
category: method
medium: [video]
models: [higgsfield, seedance-2]
tags: [camera, emotion, handheld, direction]
source: higgsfield-camera skill
---
Anger / tension → jittery handheld, small irregular micro-twitches, no stabiliser
Calm / control → smooth handheld breathing, steady rhythm
Sadness / vulnerability → slow, low handheld, slight downward drift
Shock / revelation → static, sharp freeze, then very slow push-in or pull-out
Action → 60fps, 180° shutter, clean motion blur
Final beat / verdict → top-shot freeze, 0.3-0.5s
Emotional breakdown → slow pull-back from close to wide ("leave the character alone")

If the emotion changes within a take, write named phases and change the camera with it.
